# YibinThesis 写作与 LaTeX 编写

帮助用户规划、撰写和修改论文内容，并将内容组织为 YibinThesis 可用的 LaTeX 源文件。写作规则和作者接口见本技能随附的参考文档；排版和输出由插件处理。

## 按任务读取

- 写作任务先读取[通用写作要求](references/writing-requirements.md)，再只读取本次文种对应的指南，不默认加载全部文种：
  - 正式论文的规划、摘要、绪论、主体分析或结论：读取[正式论文写作](references/thesis-writing.md)。
  - 文献综述的材料综合、导言、主题分析或总结：读取[文献综述写作](references/literature-review-writing.md)。
  - 开题报告的研究计划与表单内容：读取[开题报告写作](references/proposal-writing.md)。
- 编写入口、章节、摘要、引文或元数据：读取[LaTeX 作者接口](references/latex-writing.md)。
- 输入公式与解释变量：再读取[公式编写](references/equations.md)。

## 使用方式

从用户请求或已有稿件识别文种、学科和本次写作范围。能从现有材料确定的信息直接采用；只有缺项会影响写作内容或适用要求时才向用户询问。没有现成源文件时，可以先给出正文或建立所需的 LaTeX 文件。

按所选文种指南处理用户提供的研究材料和文献。仅修改 LaTeX 语法时读取作者接口即可；只有涉及内容调整时才补读相应写作指南。保留已确认的题目与事实；缺少结果、数据或来源时明确留待补充，不编造。元数据使用用户提供的资料，未提供的姓名、学号或导师信息留空。

按用户需要交付正文片段或更新其 LaTeX 稿件。检查本次内容、引文和源文件引用，待补充事项另列，不混入正文。需要排版或生成输出时使用插件提供的功能，不将写作任务扩展为修改插件代码。
