# 公式输入、符号与引用

作者写清公式、符号、单位和文献出处，YibinThesis 负责公式编号、Word 原生公式和版式。以下示例仅展示语法。

## 基本写法

| 事项 | 写法 |
|---|---|
| 编号 | 按章连续编号，如 3.1、4.1；编号用圆括号，位于右侧行末。作者写公式与标签，居中、编号位置和间距由工具处理 |
| 引用来源 | 在介绍公式或模型的正文中用 `\cite{key}` 标明出处，说明适用条件 |
| 符号说明 | 首次出现时说明符号含义；符号较多时可集中列符号表，过长推导可放附录 |
| 量和单位 | 使用以国际单位制（SI）为基础的单位；非物理量可用汉字与符号组合单位，如元/km |
| 交叉引用 | 正文写“式`\eqref{eq:...}`”，得到带括号的公式编号 |

保持同一符号的含义一致，说明必要条件与单位，无量纲量按需要注明。数学符号写在数学模式中，单位用 `\mathrm{m}`、`\mathrm{s}` 等写法。

## 选择公式环境

| 输入 | PDF | Word |
|---|---|---|
| `equation` ＋ `\label` ＋ `\eqref` | 按章编号及引用 | 正式论文 `thesis` 支持可编辑公式、编号和引用 |
| `align` ＋逐行标签 | 多行对齐、逐行编号及引用 | 暂不支持对应的逐行编号与引用 |
| `\[...\]`、`equation*` | 无编号陈列公式 | 无模板公式编号 |
| `align*` | 无编号多行公式 | 仅建议用于 PDF 输出 |

PDF、Word 双输出的正式论文优先使用 `equation`。当前文献综述和开题报告的 Word 输出暂不支持完整的公式编号与引用。

### 正式论文的带编号公式

```tex
\begin{equation}
  v = \frac{s}{t}
  \label{eq:average-speed}
\end{equation}
式\eqref{eq:average-speed}中，$v$ 为平均速率，单位为
$\mathrm{m\,s^{-1}}$；$s$ 为路程，单位为 $\mathrm{m}$；
$t$ 为时间，单位为 $\mathrm{s}$，且 $t>0$。
```

引用文献中的具体定义、模型或推导时，在相邻正文中补充出处和适用条件。

`\label` 放在相应公式环境内，标签全文唯一。`\eqref` 自带圆括号，`\ref` 只输出编号；不要再给 `\eqref` 手加一层括号。公式交叉引用是句中引用，与上标文献编号分开。

公式编号统一使用阿拉伯数字“章号.章内序号”，由章节和公式顺序自动产生，无需手写 `(3.1)` 或 `\tag`。调整章次和公式顺序时，在 LaTeX 源文件中修改后重新生成。

### 仅需要 PDF 时的多行示例

```tex
\begin{align}
  (a+b)^2 &= a^2 + 2ab + b^2 \label{eq:square-sum}\\
  (a-b)^2 &= a^2 - 2ab + b^2 \label{eq:square-difference}
\end{align}
其中，$a$、$b$ 为实数。
```

相互独立的公式可以分别写成 `equation`。需要用多行对齐表达推导关系时，保留数学含义，并使用支持该形式的输出。
