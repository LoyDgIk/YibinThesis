# 开题报告写作

按用户正在采用的开题表单组织内容。本页给出栏目写作指引，不替代用户提供的具体表单要求；LaTeX 字段见[作者接口](latex-writing.md)。

## 栏目与作用

| 栏目 | 写作重点 |
|---|---|
| 选题意义 | 说明实际问题、研究价值及选题边界，不以宏观背景替代具体问题。 |
| 国内外研究现状 | 比较相关成果、方法与不足，说明本选题承接什么，不逐篇堆列摘要。 |
| 研究内容 | 把研究问题分解为可执行任务，说明研究对象、范围和拟形成的成果。 |
| 方法、技术路线及可行性 | 说明各方法如何回答问题、材料从何取得、分析如何推进，以及现有条件和限制。 |
| 工作安排 | 给出能够执行的阶段任务和预期产出，与材料取得、研究实施和写作时间对应。 |
| 参考文献 | 列出实际用于选题和方案论证的来源，按具体表单核对数量，不自动沿用正式论文或综述门槛。 |
| 导师意见 | 只填写实际提供的意见，未提供时留空。 |

## 表达与核对

已有基础与未来任务分别说明，未完成工作用“拟研究”“计划采用”等措辞。预期成果是计划交付的内容，不是已得到的数据或已验证效果。

核对研究问题、内容、方法、材料、进度是否相互支持。材料无法取得或方法条件不足时，说明具体缺项并调整可行范围，不虚构完成记录。字段或栏目存在差异时，以用户本次采用的表单为准。
